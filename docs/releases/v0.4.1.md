# 知君 0.4.1 · Windows 测试版

## 更新内容

- 登录前可从右下角“连接服务”搜索局域网万象WANX，也可手动输入地址；进入知君后隐藏该入口。
- 从万象“专家 → 我的专家”自动匹配知君。只有一个可用知君时直接连接，有多个时显示选择弹窗并记住本次选择。
- 修复个人／工作等角色无法创建或使用的问题。共享来源专家使用当前账户的私人实例，各角色的对话、记忆、知识库和本体继续隔离。
- 取消仅前端的滑动验证，保留服务端要求的第三方验证码；完善桌面会话与服务地址保存。

## 下载和使用

下载 `Zhijun-Setup-0.4.1-x64.exe`，适用于 Windows x64。安装程序可选择安装目录，并创建“知君”快捷方式。旧版本 Release 保留。

这是连接现有部署的轻客户端。它沿用 0.4.0 的知君服务绑定，内置服务地址与公开证书；不包含账户密码、私人证书密钥、会话或个人记忆。首次连接先查找已绑定的知君 HTTPS 服务，再通过该服务登录万象。它不是直接连接任意 WANX 的通用独立客户端。

**知君服务端需要同步更新到本版本源码。** 局域网 WANX 搜索、自动选择专家和角色创建均包含服务端改动；只安装 EXE 不会更新服务器。局域网搜索范围是运行知君服务的电脑所在网络。WANX 广播扩展的安装条件见 [连接说明](../LAN-CONNECTION.md)，现有服务器不要覆盖其私有 `deployment.json`、证书、会话或角色目录。

## 测试版边界

安装包未做 Windows 代码签名，尚未在真实 Windows 电脑上完成安装与运行验收；Windows 可能显示发布者未知或 SmartScreen 提示。打包检查确认安装载荷、版本、图标和内嵌前端与源码一致，但不代替 Windows 实机测试。

现有服务绑定面向原有家庭／局域网部署；发布安装包不代表开通了公网远程访问。服务器需保持运行，账户、模型、对话、记忆和知识库由服务器提供。

同一 Release 提供 `SHA256SUMS.txt`，可用于校验下载的安装包。
