# 知君 0.4.2 · Windows 直连修复版

修复 0.4.1 打开后仍出现“家里的知君／配对码”旧连接页的问题。

- 启动直接进入高山流水登录页。
- 登录页右下角“连接服务”在本机局域网搜索万象WANX，也可手动输入 WANX 地址。
- 直接使用所选 WANX 的账号登录；默认连接其“我的专家”中的知君，多个可用知君才弹窗选择。
- 进入应用后隐藏“连接服务”。不再依赖 Mac 的知君 HTTPS 网关、固定服务证书、旧配对码或内置远程网络进程。
- 本机只保存连接地址、角色索引和加密会话；记忆、对话、知识库与专家实例仍由 WANX 保存。

## 安装与升级

下载 `Zhijun-Setup-0.4.2-x64.exe`，关闭旧客户端后安装。支持 Windows x64，沿用原应用标识与安装位置；不用删除旧数据目录。

第一次启动请在右下角选择你的 WANX，然后重新登录。可以输入类似 `http://192.168.1.20:8088` 的局域网 WANX 地址；不要使用旧知君网关的 28733 端口。搜索需 WANX 开启广播，未开启时仍可手动连接。安装此版本不会修改或重启 WANX 服务。

旧客户端配置和服务器数据会保留，旧配对会话不再读取。旧网关本地维护的角色索引不会自动迁入直连客户端，原专家实例、对话和记忆仍保留在服务器上。更多说明见 [连接方式](../LAN-CONNECTION.md) 与 [数据位置](../CONFIGURATION.md)。

## 验证与边界

检查实际桌面程序启动页、连接面板、本机发现范围、直接登录、会话恢复及旧配置保留，并检查安装包中不包含旧连接页面、固定服务配置或远程网络进程。

这是未签名的测试版，Windows 可能显示发布者未知提示。自动化程序启动检查不代替真实笔记本上的安装、局域网联网和使用验收。此版本的连接入口面向局域网，不表示已经开通公网远程访问。
