# 知君 0.4.4 · 微信互动与设置中心

Windows x64 测试版，安装文件：`Zhijun-Setup-0.4.4-x64.exe`。

## 本次更新

- 微信连接增加主动联系程度：仅回复、偶尔关心、适度关心、更多陪伴；支持设置可联系时段，并沿用每个角色独立的万象主动关心调度。
- 对话列表和标题显示微信、客户端等来源标签；对话列表自动刷新，切换角色时清除旧角色视图并丢弃过期请求。
- 左下角入口统一为“设置中心”，设置分类采用与记忆页一致的顶部横向导航。
- 微信“仅本人”校验：扫码绑定由万象服务端确认身份，拒绝其他联系人、群聊及角色不匹配消息；旧绑定需重新扫码。
- 保留局域网搜索、手动地址、万象登录和自动选择知君专家的连接流程；安装包不包含旧配对连接页面。

## 使用说明

- 客户端需要连接运行中的万象WANX后端。微信本人绑定需要后端安装匹配的补丁；安装 EXE 不会自动更新万象后端。部署步骤见 `docs/ONTOLOGY-DEPLOYMENT.md`。
- 主动联系与本角色“记忆 → 主动关心”共用配置；微信须已启用且有聊天会话。设置的是尝试联系的节奏，不保证每次发送。打开设置不会自动修改现有频率。
- 本版为未签名测试安装包，不含代码签名证书。Windows 可能提示发布者未知；校验 SHA-256 并遵守设备的安装策略。
- 本地真实微信验证已确认：聊天进入当前角色记忆，明确本体确认写入当前角色，其他角色未出现该会话。Windows CI 检查客户端启动与打包内容，未替代真实 Windows 设备上的微信联调。
