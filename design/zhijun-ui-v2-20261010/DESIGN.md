# 知君 UI V2 · 个人的不同侧面

参考：现有知君测试客户端的 home.png、profile-radar.png、roles-live.png，以及 docs/DESIGN.md。

## 颜色
沿用知君暖纸白 #fffcf6、深墨 #2e302c、朱红 #a6452e。纸底与侧栏只有轻微明度差；细线 #e4ded2；次要文字 #888477。朱红留给品牌印章与主要操作。

## 字体
中文大标题使用 Songti SC / STSong / Noto Serif CJK SC；正文使用系统黑体。标题 42–54，正文 14–16，注释 11–12。少量英文用于书页眉，不作为必读信息。

## 布局
固定窄侧栏，顶部显示所在页面与当前角色。对话保持大留白。记忆分为认识自己、回看来处、相处方式，次级目录放在内容侧边，避免九个标签拥挤。资料使用目录式列表；角色使用编号与定位陈述。

## 组件与交互
角色选择始终可达；切换时对话、记忆、资料同步切换。创建表单只有名称和定位，清楚说明独立空间。记忆条目区分示例中的待确认、本人确认与本人修正，详情展示来源与修正入口。页面是独立交互原型，所有内容明确为示例，没有后台、模型或真实用户数据连接；状态只保存在此原型的浏览器存储中。

## 范围
对话首页与演示发送、角色切换/创建、记忆分组/来源/确认/修正、资料预览、阅读与记忆设置。适配桌面与手机，支持键盘焦点、对话框焦点约束与减少动态效果。原生九个记忆视图的整合仅为导航方案，未删除现有客户端功能。
